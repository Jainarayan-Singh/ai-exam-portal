Exam Structure Category, Subcategory, Exam, Subject and Questions

Exams are organized in a hierarchy so students can browse them logically instead of one long flat list:

Category e.g. "SSC JE" ↓ Subcategory e.g. "Civil" ↓ Exam e.g. "SOM Test 1" — belongs to one Category + Subcategory ↓ Questions belong to one Exam

Category and Subcategory are managed together on the Manage Categories page — each category can have any number of subcategories underneath it. Every exam is assigned to one category and (optionally) one subcategory when it's created, which is what determines where it appears when a student browses exams.

Subjects are a separate, parallel concept — not a level inside the exam hierarchy. A subject is a named folder used to organize question images (see Images below). You'll typically create one subject per topic area (e.g. "Civil-SOM") and reference it in a question's Image Path as SubjectName/filename.ext.

Questions always belong to exactly one exam (via the exam you select when adding them) and can optionally reference an image stored under a subject.

Creating an Exam — Step by Step From an empty portal to a live, attemptable exam
  1. Create or select a CategoryOpen Manage Categories. If the right category doesn't exist yet (e.g. "SSC JE"), create it.
  2. Create or select a SubcategoryFrom the same page, open the category's Subcategories and add one if needed (e.g. "Civil").
  3. Create the ExamOpen Manage Exams → Add Exam. Assign the Category/Subcategory, and set the name, duration, positive/negative marks, max attempts, result mode and passing percentage.
  4. Set up a Subject (if the exam uses images)Only needed when questions will include images — create/reuse a subject on Manage Subjects to act as the image folder.
  5. Add QuestionsOpen Manage Questions, select your exam, and add questions using whichever method fits — see Adding Questions.
  6. Configure exam settingsDouble-check duration, marks, attempts and result mode on Manage Exams before publishing.
  7. Review the questionsUse the search and type/image filters on Manage Questions to check everything looks right.
  8. Publish the examSet the exam's status to Published on Manage Exams so students can see and attempt it.
An exam left in Draft status won't appear to students — if a finished exam still isn't showing up, check its status first.
Adding Questions Every way to get questions into an exam

All of these live on the Manage Questions page, once an exam is selected:

Single question

Click Add Question to open a form for one question — text, four options, correct answer, type (MCQ / MSQ / Numerical), marks, an optional image path, and an optional Source / Previous Year Tag (e.g. "ESE 2021"). Best for one-off additions or corrections.

Batch Add

The Batch Add Questions panel at the bottom of the page lets you add several rows at once, fill in each one, then save them all together with Add All Questions. Good for adding a handful of questions without leaving the page.

CSV Import

Click Import CSV to open the CSV Upload & Editor. Upload or paste a CSV, preview and edit every row (including LaTeX formatting), then save to the database. Best for adding many questions at once, especially ones already prepared in a spreadsheet.

CSV Export

Click Export CSV on Manage Questions to download all of an exam's questions — useful for backups, bulk editing offline, or moving questions between exams.

Use single-add for corrections, Batch Add for a handful of new questions, and CSV Import for large sets or anything prepared outside the portal.

AI Question Generation Generate, review and save questions with AI
  1. Start a generation jobOpen the AI Command Centre, give it a topic (or a source PDF) and start generation. It runs in the background with live progress.
  2. Review the generated questionsOnce complete, the questions load into the same CSV Editor used for CSV import — each one shown as a card with raw/rendered LaTeX views.
  3. Edit anything that needs itFix wording, adjust marks or tolerance, change the LaTeX size, delete a question you don't want, or add a Source / Previous Year Tag — the AI never invents one on its own.
  4. Save to the examClick Save to DB to add the reviewed questions to the selected exam, or Export CSV to keep them as a file instead.
Always review AI-generated questions before saving — check the correct answer and any LaTeX rendering, the same way you would for a manually written question.
AI Command Centre
Images in Questions Uploading and referencing question images
  1. Upload the imageOpen Upload Images and upload the file under the appropriate subject.
  2. Reference it in a questionIn the question's Image Path field (single-add, batch-add, or CSV), enter SubjectName/filename.ext — matching the subject you uploaded it under.
  3. It appears automaticallyOnce saved, the image renders with the question wherever it's shown — the question form, exam page, and response review.

For direct browsing or cleanup of stored files, use Object Storage, which shows the underlying folders and files as uploaded.

Import / Export Moving questions in and out of the portal

Import

From Manage Questions → Import CSV (or from a completed AI generation job). Required columns:

ColumnNotes
exam_idMust match an existing exam
question_textRequired
option_a – option_dLeave blank for Numerical questions
correct_answerOption letter(s) or numeric value
question_typeMCQ, MSQ, or NUMERIC
image_pathOptional — SubjectName/filename.ext
positive_marks, negative_marks, tolerancetolerance only used by Numerical questions
source_tagOptional — e.g. "ESE 2021"; leave blank or omit the column entirely if not applicable

Rows missing a required field are skipped, and you'll see how many rows were imported vs. skipped after saving. A "Sample CSV" download is available on the CSV Editor if you need a starting template.

Export

From Manage Questions → Export CSV for a selected exam, producing the same column set as import (so an export can always be edited and re-imported). The CSV Editor also has its own Export CSV for whatever set of questions is currently being reviewed there.

Organizing Subjects, Categories & Subcategories A practical example — not fixed application data

There's no single "correct" way to organize a portal — here's one practical example:

SSC JE (Category) ⌢ Civil (Subcategory) ⌣ SOM Test 1 (Exam) ⌣ Surveying Test 1 (Exam) ⌣ PYQs (Exam)

Subjects follow the same idea but organize images rather than exams — e.g. a subject named Civil-SOM holding every image used by Strength of Materials questions. This is only an example of a sensible structure; none of these names are built into the application.
